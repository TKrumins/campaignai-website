# CampaignAI Website — Handoff Documentation

This folder is the project handoff pack — enough for a new teammate (human or AI)
to take over the CampaignAI marketing site with full context. Read in order:

1. **[PROJECT-OVERVIEW.md](./PROJECT-OVERVIEW.md)** — what the product/site is,
   current status & deploy state, tech stack, architecture, brand system,
   content guardrails, the decision log, and every open item. **Start here.**
2. **[SITEMAP.md](./SITEMAP.md)** — every route, grouped, with purpose, nav
   placement, index status, and current state.
3. **[PAGE-COPY.md](./PAGE-COPY.md)** — the full copy deck: every user-visible
   string, organized by page → section, quoted verbatim, for copy review.

_Maintained on branch `feat/content-pages`. Last updated 2026-07-13._

> When the site changes materially, update these three files in the same commit
> so the handoff pack never drifts from the build.
