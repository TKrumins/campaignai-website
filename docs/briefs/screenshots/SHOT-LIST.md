# Screenshot Shot List — one pass at localhost:3000

Capture these once, drop them in this folder (or straight into the chat) named by the numbers below. Each page's brief references its own list; this is the consolidated checklist so you can do it in a single sitting. Save PNGs; name like `01-3_final-week-dense.png`.

**Two global captures to take once (used by every brief):**
- [ ] A full page at desktop width (~1440px) for context.
- [ ] The same at mobile width (~390px). Chrome/Edge/Firefox devtools device toolbar is fine.

**Motion tip:** for the flip, the machine, and the scroll, a short screen recording (GIF/MP4) beats stills. If you can only do stills, grab the start-state and end-state of each motion.

**Reduced motion:** to capture the fallback states, turn on your OS "reduce motion":
- Windows: Settings → Accessibility → Visual effects → Animation effects → Off.
- Then reload the page; the reduced-motion layout renders.
