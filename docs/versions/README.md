# Website version log

A running record of what changed on the CampaignAI website, in plain English,
one entry per tranche of work.

The point is that anyone — not just whoever built it — can open this folder and
see what the site looked like at each stage, what changed, why, and what was
left open.

## How the numbering works

Three numbers, `major.minor.patch`:

- **Major** — a rebuild or a relaunch. The site is meaningfully a different
  thing than it was.
- **Minor** — new pages, new sections, new features. The site gained something.
- **Patch** — corrections to words, numbers and facts on pages that already
  exist. Nothing new is built and nothing moves.

A pass that only fixes copy gets a patch number, which is why the September 2026
content corrections are 2.2.1 rather than 2.3.

Versions 1.x through 2.2 are recorded here from the build history rather than
written at the time. They are deliberately coarse — enough to place each stage,
not a reconstruction. Entries from 2.2.1 onward are written as the work happens.

## What belongs in an entry

Each entry answers four questions:

1. **What changed** — in words a person outside the project can follow.
2. **Where it changed** — which pages someone should look at.
3. **What was deliberately left alone** — so nobody re-litigates it later.
4. **What is still open** — decisions that were flagged rather than guessed.

That last section is the important one. It is where work gets handed forward
instead of lost.
